One commit message for a bug fix that made everything worse, entered in the
[Worst Fix Ever: Funniest Commit Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722)
competition on [make.fun](https://make.fun).

The entry:

> `fix: fixed the 500 error by returning 404 for everything`

`main.py` (standard library only) writes that line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is 56 characters, one line,
no trailing newline — the 500 is technically gone, because now
every page is a 404.
